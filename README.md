# Number Bomb Party Game

A Windows desktop party game built with Tauri and Rust.

## Features
- Number Bomb modes: 1–30, 1–50, 1–100; fixed 10-cell rows.
- Wheel with 12/24/48/all sectors and player ownership.
- 1–8 players with editable names.
- Screen OCR for player names using Windows.Media.Ocr.
- Offline WinRT speech with multiple voices and adjustable rate.
- Packaged Windows program included in the repository backup.

## Build
```powershell
cd 源码/src-tauri
cargo build --release
```

## Platform
Windows desktop only. No web version.
